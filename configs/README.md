# Configuration templates

- `bundle.example.json`: external inference weights, gene dictionary, Program mapping and codebook paths.
- `preprocessing.example.json`: per-stage inputs, fresh outputs and GPU selection.
- `train.example.json`: native distributed recovery/continuation training settings.

Copy templates to local configurations and replace placeholder paths before use. Preview commands before enabling execution. Keep machine-specific configurations and assets out of Git.
